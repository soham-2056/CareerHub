# CareerHub 🚀

A Full Stack Career Management Platform built using React, Node.js, Express.js, and MongoDB Atlas.

## 🌐 Live Demo

Frontend:
https://career-hub-neon-alpha.vercel.app

Backend API:
https://careerhub-api-mvti.onrender.com

## ✨ Features

* User Registration & Login
* JWT Authentication
* Resume Management
* Skills Tracking
* Internship Portal
* Interview Preparation
* User Dashboard
* MongoDB Atlas Integration

## 🛠 Tech Stack

### Frontend

* React
* Vite
* Axios
* React Router

### Backend

* Node.js
* Express.js
* MongoDB Atlas
* JWT Authentication
* bcryptjs

## 🚀 Installation

### Clone Repository

git clone https://github.com/soham-2056/CareerHub.git

### Frontend

cd client

npm install

npm run dev

### Backend

cd server

npm install

npm run dev
