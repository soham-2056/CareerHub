# CareerHub 🚀

A Full Stack Career Management Platform that helps students and job seekers manage their professional growth through resume management, skill tracking, internship opportunities, and interview preparation.

## 📖 About The Project

CareerHub is designed to provide a centralized platform for students and aspiring professionals to manage their career journey. The platform offers authentication, profile management, resume handling, internship exploration, skill tracking, and interview preparation features.

This project demonstrates modern full-stack web development practices using React, Node.js, Express.js, and MongoDB Atlas.

## 🚀 Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/soham-2056/CareerHub.git
```

### 2️⃣ Frontend Setup

```bash
cd client

npm install

npm run dev
```

### 3️⃣ Backend Setup

```bash
cd server

npm install

npm run dev
```

### 4️⃣ Environment Variables

Create a `.env` file inside the `server` folder:

```env
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
ACCESS_TOKEN_EXPIRY=15m
REFRESH_TOKEN_EXPIRY_DAYS=7
ALLOWED_ORIGINS=http://localhost:5173
```
